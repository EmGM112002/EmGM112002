# Proyectos destacados

## Tarificación actuarial

### [Calculadora de Primas de Seguro de Vida](https://github.com/EmGM112002/calculadora-primas-seguro-vida)

Herramienta actuarial desarrollada en **Excel y VBA** para automatizar el cálculo de primas de diferentes productos de seguro de vida individual utilizando tablas de mortalidad y valores actuariales.

La herramienta integra cálculos actuariales, validaciones de entrada, parámetros financieros y automatización mediante macros.

**Temas:** seguros de vida, tablas de mortalidad, primas netas, primas brutas y automatización actuarial.

`Excel` `VBA` `Seguros de Vida` `Matemáticas Actuariales`

---

### [Tarificación de Seguro de Gastos Médicos mediante GLM](https://github.com/EmGM112002/tarificacion-seguro-gastos-medicos-glm)

Modelo de tarificación desarrollado en **Python** mediante un **Modelo Lineal Generalizado Tweedie con enlace logarítmico** para estimar costos esperados y obtener relatividades de riesgo interpretables.

El proyecto incorpora ajuste por exposición, factores de riesgo categóricos, intervalos de confianza, validación cruzada y evaluación fuera de muestra.

**Temas:** GLM Tweedie, tarificación, relatividades de riesgo, exposición y modelación predictiva.

`Python` `statsmodels` `scikit-learn` `GLM` `Gastos Médicos`

---

## Reservas y siniestralidad

### [Estimación de Reservas IBNR mediante Chain-Ladder](https://github.com/EmGM112002/reservas-ibnr-chain-ladder)

Implementación en **Python** del método clásico de **Chain-Ladder determinista**, utilizando el triángulo acumulado de desarrollo de siniestros RAA.

El modelo calcula explícitamente factores de desarrollo edad-a-edad, siniestros últimos y reservas IBNR.

**Temas:** triángulos de desarrollo, Chain-Ladder, siniestros últimos e IBNR.

`Python` `pandas` `chainladder` `Reservas Actuariales`

---

### [Dashboard de Siniestralidad para Seguro de Automóviles](https://github.com/EmGM112002/dashboard-siniestralidad-seguro-automoviles)

Dashboard interactivo desarrollado en **Power BI** para monitorear una cartera de seguro de automóviles mediante indicadores de primas, exposición, frecuencia, severidad, Loss Ratio y reservas.

El proyecto utiliza un modelo dimensional y medidas construidas en DAX para analizar el comportamiento de la cartera por periodo, cobertura y región.

**Temas:** siniestralidad, frecuencia, severidad, Loss Ratio, segmentación de cartera e inteligencia de negocio.

`Power BI` `DAX` `Power Query` `Seguro de Automóviles`

## Pasivos laborales y gestión de riesgos

### [Cálculo de la Obligación por Beneficios Definidos mediante PUC](https://github.com/EmGM112002/calculo-obligacion-dbo-metodo-puc)

Modelo actuarial desarrollado en **Python** para estimar la **Obligación por Beneficios Definidos (DBO)** y el Costo Normal de una población de empleados mediante el método de **Unidad de Crédito Proyectada (PUC)**.

El modelo integra proyección salarial, mortalidad, probabilidades de supervivencia, descuento financiero y atribución del beneficio.

**Temas:** beneficios definidos, DBO, PUC, mortalidad y valor presente actuarial.

`Python` `pandas` `NumPy` `pymort` `Pasivos Laborales`

---

### [Análisis de Sensibilidad y Estrés en Pasivos Laborales](https://github.com/EmGM112002/analisis-estres-pasivos-laborales)

Modelo actuarial desarrollado en **R** para analizar el impacto de cambios en la tasa de descuento, crecimiento salarial y longevidad sobre obligaciones laborales de largo plazo.

El proyecto compara diferentes escenarios deterministas contra una valuación central para identificar los factores con mayor impacto sobre el pasivo.

**Temas:** análisis de sensibilidad, tasa de descuento, inflación salarial, longevidad y gestión de riesgos.

`R` `dplyr` `ggplot2` `lifecontingencies` `Gestión de Riesgos`

## Datos y automatización en seguros

### [Reconciliación de Datos y Cálculo de Prima Devengada con SQL](https://github.com/EmGM112002/reconciliacion-datos-prima-devengada-sql)

Proyecto desarrollado en **PostgreSQL** para simular, procesar y reconciliar una cartera de más de **un millón de pólizas**, junto con información de endosos y siniestros.

El proyecto reconstruye la vigencia contractual y los movimientos financieros de las pólizas, y calcula la prima devengada utilizando un criterio **pro rata temporis**.

**Temas:** prima devengada, conciliación transaccional, pólizas, endosos, siniestros y optimización SQL.

`PostgreSQL` `SQL` `CTEs` `Funciones de Ventana` `Datos de Seguros`

## Analítica predictiva

### [Predicción de Demanda de Transporte Compartido](https://github.com/EmGM112002/prediccion-demanda-transporte-compartido)

Proyecto de Machine Learning desarrollado en **Python** para predecir demanda horaria de transporte utilizando variables temporales y un modelo **Random Forest Regressor**.

Los hiperparámetros son seleccionados mediante `GridSearchCV` y el modelo se evalúa utilizando MAE, RMSE y R².

### Desempeño del modelo

| Métrica | Resultado |
|---|---:|
| MAE | 14.79 viajes |
| RMSE | 21.32 viajes |
| R² | 0.8953 |

**Temas:** regresión, Random Forest, ingeniería de variables, validación cruzada y modelación predictiva.

`Python` `pandas` `scikit-learn` `Random Forest` `Machine Learning`
